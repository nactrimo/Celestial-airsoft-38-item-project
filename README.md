# Bombe Airsoft - Remake 🧨

Ce projet est un **remake complet** d'une bombe pour notre association d'airsoft. Il inclut plusieurs modes de jeu et apporte des améliorations significatives par rapport à la version originale.

## Origine du projet  
Le projet est inspiré d'un code initial disponible ici : [Lien vers le projet original](inserer-le-lien). Cependant, la version originale présentait plusieurs limites :  
- De nombreux bugs affectant le fonctionnement.  
- Une interface et des textes uniquement disponibles en espagnol.  
- Des fonctionnalités qui ne correspondaient pas pleinement à nos besoins en tant qu'association d'airsoft.  

C'est pourquoi j'ai entrepris de créer un **remake complet**, adapté aux spécificités de nos parties et conçu pour offrir une expérience fluide et immersive.

---

## Fonctionnalités 🎮  
- **Modes de jeu personnalisés** : Plusieurs modes sont disponibles pour s'adapter à différents scénarios airsoft.  
- **Interface utilisateur multilingue** : Texte en français pour une meilleure accessibilité.  
- **Fiabilité et stabilité** : Code revu et corrigé pour éliminer les bugs.  
- **Configuration facile** : Les paramètres peuvent être ajustés pour correspondre aux besoins spécifiques de chaque partie.  
- **Évolutivité** : Une base de code propre permettant l'ajout facile de nouvelles fonctionnalités.
